# Fetal Health Classification

An end-to-end Machine Learning pipeline implemented in Python and R to classify fetal health states into **Normal**, **Suspect**, or **Pathological** using the *fetal_health.csv* data. 

## Models Implemented
* **Decision Tree** (Baseline model optimized for interpretability)
* **Random Forest** (Hyperparameter tuned via 5-fold Cross-Validation)
* **Gradient Boosting** (Hyperparameter tuned via 5-fold Cross-Validation)
